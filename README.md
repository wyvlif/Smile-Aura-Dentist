# SMILE AURA DENTIST

Public website for SMILE AURA DENTIST in Remera, Kigali. It is a single static page (`index.html`) hosted on Netlify at https://smile-aura250.netlify.app.

## Features

- Clinic information: services, gallery, about, testimonials, contact and map link.
- **Appointment requests** use Netlify Forms. Each request appears in the Netlify dashboard under **Forms → appointment**. To get an email for each new request, go to **Forms → Form notifications → Add notification**.
- WhatsApp quick-contact button.
- A dental FAQ assistant that runs in the browser (general information only).

## Editing

Edit `index.html` (on GitHub with the pencil icon, or locally) and commit to `main`. Netlify redeploys automatically.
